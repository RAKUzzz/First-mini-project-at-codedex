# Area Calculator 📐  

A simple Python program to calculate the area of different geometric shapes.  
This project demonstrates the use of conditionals, loops, and basic math functions in Python.

---

## Features ✨
- Menu-based selection for shape type  
- Supports four shapes: Triangle, Rectangle, Square, Circle  
- Input validation (forces user to enter valid numbers)  
- Clear output with emoji for fun readability  

---

## Installation ⚙️
1. Make sure you have **Python 3.x** installed ([Download here](https://www.python.org/)).  
2. Clone the repository or download the project files:  
   ```bash
   git clone https://github.com/<username>/area-calculator.git
   cd area-calculator
   ```

---

## Usage 🖥️
Run the program with:  
```bash
python area_calculator.py
```
